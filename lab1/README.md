# Лабораторная работа №1: Предобработка текста

**Дисциплина:** Обработка естественного языка (Natural Language Processing)  
**Институт:** ИПМКН ТГУ  

---

## 📌 Постановка задачи
Требуется прочитать текст на русском языке из файла и вывести все пары соседних слов, которые:
1. Имеют имена существительные или имена прилагательные на первом или втором месте (всего четыре возможные комбинации: `ADJF + NOUN`, `NOUN + ADJF`, `ADJF + ADJF`, `NOUN + NOUN`).
2. Совпадают по роду, числу и падежу.
3. Выводятся в виде лемм (начальных словарных форм). Например: `необычайных университетов` ➔ `необычайный университет`.
4. Пары определяются после сегментации на предложения и токенизации текста на слова (пары ищутся строго в пределах одного предложения).

---

## ⚙️ Особенности реализации
- **Сегментация и токенизация:** Выполняются с помощью библиотеки `nltk` (`sent_tokenize` для разбиения на предложения и `word_tokenize` для разбиения на слова с отсечением знаков препинания).
- **Морфологический анализ:** Используется библиотека `pymorphy3` на основе словарей `OpenCorpora`.
- **Разрешение омонимии:** Перебираются варианты разборов слов для корректного сопоставления падежей и грамматических характеристик.
- **Согласование во множественном числе:** В русском языке у полных прилагательных во множественном числе категория рода не различается (`tag.gender is None`). Алгоритм корректно учитывает эту лингвистическую особенность: во множественном числе проверяется совпадение числа и падежа.
- **Нормализация буквы «ё»:** Слова, записанные через «е» (например, *«клен»*), лемматизируются в их словарную норму с буквой «ё» (*«клён»*).

## 🚀 Установка и запуск

### 1. Установка зависимостей
Рекомендуется использовать Python 3.8 или новее:
```bash
pip install -r requirements.txt
```

### 2. Запуск программы
По умолчанию скрипт считывает текст из файла `input.txt`, находящегося в той же папке:
```bash
python main.py
```

Также можно передать путь к произвольному текстовому файлу в качестве аргумента командной строки:
```bash
python main.py /path/to/your/text.txt
```
